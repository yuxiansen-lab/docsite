# 介绍

DocSite 是一个用 **Go + 原生前端** 实现的轻量文档系统。

## 设计目标

1. **轻量** — 无重型框架，前后端合计不到 2 MB
2. **可维护** — 单一职责、清晰分层、标准库优先
3. **可扩展** — 配置驱动，新增文档与菜单无需改代码

## 核心概念

| 概念 | 说明 |
| ---- | ---- |
| 站点配置 | `config/site.json`：标题、主题色、默认文档 |
| 菜单 | `config/menu.json`：支持 3 级以上的子母结构 |
| 文档 | `docs/**/*.md`：按目录组织，路径即 URL |
